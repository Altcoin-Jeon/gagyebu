# 가계부 앱이 받는 파일

- `law.json`: 가계부 앱의 급여 계산이 쓰는 법정 값(최저임금, 4대 보험 근로자 부담 요율, 공휴일). 앱이 30일마다 받아 간다.
- `index.html`: 앱의 개인정보 처리방침.

## 해마다 할 일

1. `law.json`의 `years`에 새 해를 더한다(최저임금, 국민연금·건강보험·고용보험 요율 %, 장기요양은 건강보험료에 곱하는 %, 국민연금 기준소득월액 하한·상한).
2. `holidays`에 새 해의 유급 휴일(관공서 공휴일·대체공휴일·노동절)을 `MM-DD`로 더한다.
3. 저장(커밋)하면 몇 분 뒤 앱이 받는 주소에 반영된다.

숫자는 고용노동부·보건복지부 고시와 우주항공청 월력요항에서 확인한다. 형식이 틀리면 앱은 받은 파일을 버리고 앞의 값을 그대로 쓴다.
